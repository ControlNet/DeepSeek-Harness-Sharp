## 根因与触发

保留原分支的 19 个修复提交，并合并当前 `origin/master`，没有重新实现已合入的上游改动。

| 触发/相关用例 | 根因 | 修复 |

## 验证方式

当前工具列表未提供 Rider MCP、`xdebug_*` 或 `rider_lint_files`，因此不能宣称做过 Rider/debugger 验证。
使用真实构建、编译器/分析器与测试运行器验证；构建使用 `-m:2 -nodeReuse:false -p:UseSharedCompilation=false`，完整 quick 使用两路限流中的独立槽位，定向回归不占用全局锁。
真实 TUI 夹具、外层测试进程和当前产物的 daemon 使用同一独立配置根；本地显示使用私有 Xvfb，退出时只停止本轮创建的 daemon。

CI 在 Windows、Ubuntu、macOS 先运行完整 quick，再运行相关类连续三轮；`set -e` 使任意一轮失败立即失败，三轮不是失败重试。
打开状态的 PR 直接 checkout `refs/pull/<编号>/merge`，避免 synchronize 事件里旧 `merge_commit_sha` 让新 head 的检查误测旧代码；关闭或非 PR 事件使用 `github.sha`。
macOS 沿用仓库已有的串行测试设置。
quick 排除 `GpuStress`、`OnlyGpu`、`RenderBench`、`LlmSmoke`，不把这些分类写成已通过。

## 已执行的本地结果

- schema 覆盖层修复前的完整 quick：1717 项，4 失败、5 跳过；失败为模板插件卸载后的两组 PluginTemplate/SettingsTemplate 校验。修复恢复默认上下文 schema 后，不再把该历史失败解释为环境问题。
- 已隔离配置、由当前 CLI 启动独立 daemon、已纳入真实 CLI 构建依赖及配置根修复的最终本地波：solution 构建 0 warning、0 error；完整 quick 1718 项，0 error、0 failed、5 skipped，73.362 秒。
- 同波相关类连续三轮均为 130 项，0 error、0 failed、0 skipped，分别 29.376、32.628、30.421 秒。该波不作为随后新增连接预算起点修复的 Windows 实证；后者由最终 PR 当前 merge-ref 的三平台 quick 和包含 `PtyOwnershipTests` 的三轮检查验证。
- 五项 skip 是 MongoDB 未运行、原生插件样例未发布，以及三个需要外部 SSH fixture 的用例；没有删除或禁用这些测试，不声称相关外部依赖已验证。GPU/渲染压力与真实 LLM 分类明确排除，不记为通过。

最终三平台结果、实际 checkout 与当前 head 的关联，以 PR 的检查和最终中文验收评论为准；不把关联旧 payload、实际却 checkout 旧 head 的跑次算成最终证据。
